# 🔐 Phishing Awareness Training

An interactive cybersecurity awareness module developed as part of my **Code Alpha Internship – Task 2**.

## 📌 About the Project

This project is an interactive online training module designed to help users understand phishing attacks and recognize common warning signs before becoming a victim.

## 📚 Topics Covered

- 📧 Phishing Emails
- 🌐 Fake Websites & Suspicious URLs
- 🎭 Social Engineering Tactics
- 📱 Smishing
- 🚨 Real-World Phishing Scenarios
- 🛡️ Cybersecurity Best Practices
- 🧠 Interactive Phishing Awareness Quiz

## 🎯 Learning Objectives

The module helps users:

- Identify suspicious phishing emails
- Recognize fake and malicious websites
- Understand common social engineering techniques
- Identify warning signs in suspicious messages
- Follow safer cybersecurity practices
- Test their knowledge through an interactive quiz

- HTML5
- CSS3
- JavaScript
